# Publication scope and rights review

Northstar CodeReview is licensed under the [MIT License](../LICENSE).
Copyright (c) 2026 Anvesh Tula. The owner confirmed redistribution authority for
the proposed implementation, specialist skills and fictional fixtures, and approved
disclosure of project names, repository-relative paths and aggregate evaluation
results. The exact release candidate remains subject to final verification;
licensing does not authorize a Git operation or publication.

Application code, fictional fixtures, examples, packaged specialist instructions
and documentation were developed in the project workflow. Their local presence and
fictional labels alone are not proof of legal ownership or redistribution permission.
The owner's confirmation applies to the reviewed candidate set; new contributions
or identified third-party adaptations still require review. No employer material
or private evaluation source snapshot is approved for inclusion.

No external reference document is bundled. Unconfirmed third-party snippets,
documents or assets must be excluded pending permission. The project MIT license
does not override third-party terms. Existing attribution and copyright notices
must be preserved.

Dependencies retain their separate licenses. Local package notices can document
those licenses, but do not grant rights to application content or settle every
redistribution obligation. Environments, caches, runtime results and generated
distributions are not publication candidates.

A proposed file inventory and detailed rights-review checklist are kept in ignored
project-local runtime storage for maintainer review. Neither inventory generation,
passing tests, local report approval nor this document authorizes Git operations,
public release, deployment or package publication.
